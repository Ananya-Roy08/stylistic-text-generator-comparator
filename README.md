# Stylistic Text Generator Comparator

[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/pthqsqr8cm/badge.svg)](https://ask.thili.ai/b/pthqsqr8cm)

This project, the Stylistic Text Generator Comparator, helps sports journalists evaluate and compare text generated by different language models. It fine-tunes a LoRA-adapted LLM and an N-gram model on specific sports commentary styles, providing an interface for qualitative comparison of their outputs. This allows for an objective assessment of which model best captures the desired stylistic nuances.

## What you are building

**Goal.** You will build a tool that compares text generated by a LoRA-adapted Language Model with an N-gram model, both fine-tuned on specific sports commentary styles.

**Done when.** Your project will be complete when you have successfully fine-tuned a pre-trained model with LoRA on a custom text style and can compare its text generation quality against an n-gram model built from the same text.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
python -m app.cli hello
pytest
```

Your work goes in `app/core.py` (one stub per milestone) and `tests/test_core.py`. The first tests pass already; they
check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever
