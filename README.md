# Stylistic Text Generator Comparator

This project compares cricket commentary generated by a trigram baseline and a
LoRA-adapted `distilgpt2` model. Both use the same seed prompt and a small
project-local corpus.

## Milestones

- [x] Prepare a small sports commentary corpus.
- [x] Implement the N-gram model and prompt-based generation.
- [x] Load `distilgpt2` and inject LoRA adapters.
- [x] Fine-tune and save LoRA adapter weights.
- [x] Generate from the adapted model with temperature/top-p sampling.
- [x] Display both outputs in the CLI.

## Corpus

The corpus is [`data/sports_commentary.txt`](data/sports_commentary.txt), a
20-line, original synthetic cricket commentary sample written for this project.
It was not scraped from match reports, broadcasts, or an external dataset. Each
non-empty line is one short commentary example; `app.core.milestone_1()` loads
the lines for training.

## Setup and usage

Python 3.12 is used in CI. The comparator needs no API key. The first call to
`milestone_3()` or `milestone_4()` downloads `distilgpt2` from Hugging Face if
it is not already cached; these functions can then use the cached model.

### Windows PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.cli hello
.\.venv\Scripts\python.exe -c "from app.core import milestone_4; milestone_4()"
.\.venv\Scripts\python.exe -m app.cli compare "The opening delivery"
.\.venv\Scripts\python.exe -m pytest -q
```

### macOS/Linux

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m app.cli hello
python -c "from app.core import milestone_4; milestone_4()"
python -m app.cli compare "The opening delivery"
python -m pytest -q
```

Fine-tuning saves the adapter state to `data/lora_adapter.pt`, which is ignored
by Git. The `compare` command requires that file; run the Milestone 4 command
first. Sampling options are available as `--max-new-tokens`, `--temperature`,
and `--top-p`.

The optional `.env.example` settings are for `app.llm.chat()` (an
OpenAI-compatible chat endpoint), not for the local DistilGPT2 comparator. No
`.env` file or credentials are needed for the commands above. If you use that
chat helper, copy `.env.example` to `.env` and keep real credentials out of Git.

## Example and evaluation notes

For the seed prompt `The opening delivery`, the checked-in N-gram corpus produces
this deterministic continuation. The LoRA text is an illustrative example, not
a recorded model run; actual output depends on the locally trained adapter and
sampling settings.

| Model | Example output |
| --- | --- |
| N-gram baseline | The opening delivery swings away late, and the batter watches it pass outside off stump. |
| LoRA-adapted LLM (illustrative) | The opening delivery draws a sharp swing, and the batter is beaten outside the off stump. |

This is a qualitative demo, not a benchmark. Compare prompt continuity,
cricket terminology, readability, and repetition; there is no automated quality
score or held-out evaluation set. The N-gram model is deterministic and tends
to reuse local word sequences from the training corpus. The LoRA baseline uses
an 82M-parameter pretrained model with a rank-4 adapter and one small-batch
training epoch. The 20-line synthetic corpus is intentionally tiny, so either
model may repeat phrases, generalize poorly, or produce inaccurate commentary;
the LoRA model may also vary between runs because sampling is enabled.
